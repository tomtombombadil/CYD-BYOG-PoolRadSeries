Journal Converter

The Gold Box games tell you to read entries in the printed Adventurer's Journal. This page turns your own GOG journal PDF into a file the engine shows on the board. It runs entirely in your browser: nothing is uploaded. Back to the installer

Make your journal file

  1. Find the journal PDF in your game folder. GOG puts it next to the game, for example Curse of the Azure Bonds/Adventurers Journal.pdf.
  2. Choose it below. The page checks it is a journal it knows and cuts out every entry as a picture.
  3. Save JOURNAL.BIN into the game's folder on the SD card, next to its .DAX files (for example GOLDBOX/CURSE).
