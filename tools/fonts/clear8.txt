# (2-pixel stems) letters, digits and punctuation for the 8 x 8 cells the
# games print in, with real lower case. Drawn from scratch for the engine
# (not taken from any game or font file). Each glyph: a line "= c" (the
# character), then 8 rows, '#' = ink, '.' = paper; ink in columns 0-6 and
# rows 0-6, row 7 only for descenders. tools/fonts/make_font.py turns this
# into src/engine/font_clear.cpp.
